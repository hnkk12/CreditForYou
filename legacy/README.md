# legacy/ — Phiên bản cũ (lưu trữ)

Đây là code của prototype trước (chấm điểm 0–1000, giao diện Streamlit), đã đổi tên thành CreditForYou.
**Không còn được dùng** trong hệ thống mới (`creditforyou/`). Giữ lại để tham khảo khi làm frontend.

- `app.py` — giao diện Streamlit cũ (chạy từ trong thư mục `legacy/`: `streamlit run app.py`, cần `pip install streamlit altair pypdf shap`)
- `ml/` — pipeline ML cũ (dùng nhãn vỡ nợ tự sinh bằng luật -> không dùng lại)
- `data/` — dataset mẫu cũ
- `README_legacy.md` — README gốc
